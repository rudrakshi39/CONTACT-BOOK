# CONTACT-BOOK

A simple command-line contact book written in C.

## Features
- Add a contact
- View all contacts
- Search by name
- Delete a contact
- Contacts are saved in a file, so they stay after closing the program

## How to run
gcc contact_book.c -o contact_book
./contact_book

## What I learned
Structs, arrays, functions, file handling, and string handling in C.
